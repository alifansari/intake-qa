# Engine v2 Scoring Architecture — Research Brief (Wave 12, 2026-07-11)

> **Status:** staged research brief — the LLM-engineering foundation for the v2 build.
> Companion to `engine-v2-system-prompt-DRAFT.md` (which it partially supersedes on
> architecture: the draft is a single-prompt design; this brief moves gates/aggregation/
> posture OUT of the prompt into code). The v2 build follows this document.
> **Through-line:** v2's reliability comes from *narrowing* what the LLM is trusted with
> (cited extraction, anchored dimension reads) and making everything downstream — gates,
> aggregation, posture, tiers, confidence, alerts — deterministic, versioned, and
> separately testable.

## Recommended architecture: a pipeline, not an oracle

The single strongest cross-cutting finding: **every judgment you can move out of the LLM's free discretion and into deterministic code measurably improves reliability.** The LLM should do exactly two things — extract cited facts and grade anchored dimensions — and code should do everything else (gates, aggregation, posture, tiers, alerts).

**Stage 1 — Extraction (LLM call 1).** Extract the fact schema the draft already specifies (value, citation_span, speaker, confidence, observability). Critically: reason in free text *first*, emit JSON *last*. The ["Let Me Speak Freely"](https://arxiv.org/pdf/2408.02442) line of work and its successors ([Capacity, Not Format](https://arxiv.org/pdf/2606.09410)) show format constraints degrade reasoning 10–30%, and that the damage comes from *premature serialization* — forcing schema tokens before reasoning completes; performance recovers when unconstrained reasoning precedes structured submission. So: `<analysis>` scratchpad, then the JSON object.

**Stage 2 — Gates (code, not LLM).** Fatal-fact gates evaluated deterministically from Stage-1 extracted fields: `caller_is_uninsured_owner == true AND observability == observed_on_call → prop-213 gate`. Evidence that LLMs execute lexicographic ("check fatal conditions first, then grade") instructions faithfully is thin — what's well-documented is the failure mode: judges re-interpret the rubric anew at every inference and drift ([Rulers](https://arxiv.org/html/2601.08654v1) documents "rubric instability due to prompt sensitivity" as a recurrent failure mode and compiles rubrics into executable, versioned specifications for exactly this reason). A gate in code fires identically on call 1 and call 10,000. The LLM's only gate-related job is extracting the trigger fact with a quote.

**Stage 3 — Graded dimensions (LLM, same call as Stage 1 is acceptable at temp 0).** The seven case-quality reads (strong/adequate/thin/unknown/fatal) each get: (a) a behavioral anchor description per level, not bare numbers — anchor descriptions with example inputs per level "stabilize calibration and reduce variance, similar to rater training" ([Rulers](https://arxiv.org/html/2601.08654v1); [LLM-as-judge survey](https://www.sciencedirect.com/science/article/pii/S2666675825004564) notes directly assigning coarse Likert scores is "unstable and biased" and decomposition into interpretable criteria is the fix); (b) **cite-then-claim ordering** — quote the evidence spans first, then the level. Requiring quotes from the source before the verdict "forces the generation to remain grounded in the text" ([Datadog hallucination-detection work](https://www.datadoghq.com/blog/ai/llm-hallucination-detection/); [citation-grounding research](https://arxiv.org/pdf/2606.00898)). Claim-then-cite invites post-hoc rationalization; cite-then-claim constrains the claim. The v1 prompt's "evidence or it didn't happen" already has this instinct — v2 makes the *ordering* explicit in the output schema (evidence field physically precedes level field).

**Stage 4 — Deterministic aggregation (code).** Dimension reads → disposition via an explicit decision table (any `fatal` → decline/refer per gate type; ≥N `thin` on load-bearing dims → develop; etc.), and → value tier via a lookup keyed on (case_type, dimension profile). Do not let the LLM aggregate holistically: decomposed subscores plus rule-based aggregation is the consistent reliability winner across the rubric-evaluation literature ([survey](https://www.sciencedirect.com/science/article/pii/S2666675825004564); binary/DAG sub-decisions outperform holistic scores — [aman.ai autorater primer](https://aman.ai/primers/ai/LLM-as-a-judge/)). This also makes disposition logic auditable and diffable — a compliance property, not just an engineering one.

**Stage 5 — Confidence + abstention (code, from Stage-1 metadata).** Confidence tier computed from observability counts, transcript quality, and extraction-confidence flags — *not* from asking the model "how confident are you" (LLM self-reported confidence correlates weakly with correctness; [selective-prediction literature](https://arxiv.org/pdf/2508.07556)).

**Asymmetric loss** (missing catastrophic-risk ≫ false alarm): do *not* rely on a "false negatives cost 10x" sentence in the prompt. The evidence that cost-ratio instructions alone shift LLM behavior is weak — cost framing takes effect only when coupled with extended explicit reasoning ([Act or Escalate](https://arxiv.org/html/2604.08588v1)). The mechanism that demonstrably works is *structural*: encode asymmetry as recall-tilted trigger lists (long, inclusive high-value-indicator list; any single hit forces the escalation field to be addressed with a quote or an explicit "checked, absent"), and measure it at validation as high-acuity recall — exactly how medical-triage AI handles it, rewarding top-acuity recall because under-triage is the catastrophic direction ([ED triage LLM benchmarking](https://www.researchsquare.com/article/rs-9727564/v1)). [Judgment call] Keep a one-line cost-asymmetry statement in the prompt anyway (harmless, possibly helpful with reasoning models), but treat the checklist + validation metric as the real enforcement.

## Validation protocol

- **Gold set size:** 100–150 dual-attorney-labeled transcripts for the headline QWK, stratified across the four dispositions (force ≥20 per disposition; declines/refers are rare in the wild and must be over-sampled). Kappa sample-size methodology puts ~95 cases at the point where a κ≈0.8 estimate is distinguishable with 90% power ([kappa sample-size guidelines](https://www.researchgate.net/publication/320148141_Guidelines_of_the_minimum_sample_size_requirements_for_Kappa_agreement_test)); below ~50 per comparison, QWK confidence intervals are too wide to gate a ship decision.
- **Measure the human ceiling first.** Have both attorneys label independently; their QWK is the bar. In essay scoring, human–human QWK on ASAP runs ~0.75 and the [operational acceptance standard](https://educationaldatamining.org/EDM2023/proceedings/2023.EDM-long-papers.9/index.html) is machine–human QWK ≥ 0.70 *and* within ~0.10 of human–human. In ED triage, the best structured-prompting LLM hit κ_qw = 0.747, "approaching human inter-rater reliability" ([emergency triage LLM study](https://www.sciencedirect.com/science/article/pii/S2949882126000526)). Realistic v2 targets: **disposition QWK ≥ 0.70; value-tier QWK ≥ 0.65; catastrophic/high-value-indicator recall ≥ 0.95 with precision reported but not gated.**
- **Report the direction-weighted confusion matrix**, not just QWK: sign→decline and decline→sign errors are not symmetric; a wrongful decline (the "most expensive, most invisible failure") gets 10x weight in the ship/no-ship review.
- **Abstention rules:** emit `indeterminate` tier / withhold disposition when (a) transcript-quality gate trips, (b) >2 of the 7 dimensions read `unknown` on observed evidence, or (c) any gate-relevant fact is `inferred` rather than `observed_on_call`. Measure the coverage/accuracy tradeoff explicitly (selective-prediction framing: [abstention as intentional behavior](https://www.techrxiv.org/doi/pdf/10.36227/techrxiv.175682660.02761872/v1)); target ≥85% coverage with abstained calls routed to human review. [Judgment call on the exact thresholds; the mechanism is evidence-backed.]
- **Drift:** pin the model ID; re-run the full gold set on any model/prompt/config change and block on QWK regression >0.05; keep 5–10 **canary transcripts** (one per failure mode: over-conversion, Prop-213, Spanish-language, borderline develop/sign) scored weekly in production even with no changes — providers ship behavior changes without version bumps ([golden sets + drift monitoring practice](https://medium.com/@falvarezpinto/evaluation-first-ai-product-engineering-golden-sets-drift-monitoring-and-release-gates-for-llm-2c3bfb3f1e7b), [production eval workflow](https://www.socratopia.app/library/ai-engineering-en/chapter-21)). Every production failure becomes a new regression gold.

## Few-shot gold design

The staged 6-gold set is architecturally right. The evidence: **contrastive pairs beat independent prototypes** — two golds with an identical aggressive close but opposite verdicts (because the dimension reads differ) is exactly the [contrastive in-context learning](https://arxiv.org/pdf/2401.17390) pattern, and it teaches the *decision boundary* rather than the prototype. Boundary cases > easy prototypes for a scorer whose errors all live at boundaries. On count: 4–8 is the sweet spot; [Calibrate Before Use](https://arxiv.org/pdf/2102.09690) showed more examples do *not* reduce variance (variance stays high even at 16 shots), while context cost grows linearly and long few-shot blocks dilute the rubric. On ordering: order effects are real and large (reversing two examples dropped accuracy from 88.5% to near-chance in Zhao et al.'s worst case) — so **fix the order permanently, validate QWK under that exact order, and treat gold order as part of the pinned configuration** (v1's "order 2, 1, 3" discipline is correct; keep the discipline in v2). Put the contrastive pair adjacent, and don't end on a decline (recency bias tilts toward the last label seen).

## Config-driven posture without destroying comparability

The clean solution falls out of the architecture: **the LLM never sees posture.** It emits firm-independent dimension reads and extracted facts against one fixed prompt + one fixed gold set (config supplies only facts the LLM needs: accepted case types, state). Posture (`selective|volume|off`), per-type thresholds, MIST handling, e-sign gating all live in the Stage-4 code aggregation — a volume firm's decision table converts a `thin-damages/adequate-liability` profile to `develop` where a selective firm's converts it to `decline`. Cross-firm comparability is preserved at the dimension-read layer (the same call gets the same seven reads at any firm), and posture differences are an auditable, versioned code diff. This also means posture changes need zero re-validation of the LLM — only of the decision table. [Judgment call, but directly analogous to Rulers' compiled-rubric separation and standard cost-sensitive learning, where the *threshold* moves, never the classifier.]

## Do-not-do list

1. **Don't let the LLM output the final tier/disposition directly** from a holistic read — coarse direct scores are the documented unstable path ([survey](https://www.sciencedirect.com/science/article/pii/S2666675825004564)).
2. **Don't force JSON from the first token** — reason free-form, serialize last ([format-restriction studies](https://arxiv.org/pdf/2408.02442)).
3. **Don't rely on majority-voting/self-consistency at temperature 0** — at temp 0 repeated calls are near-deterministic, so you pay 3–5x for almost no variance reduction; the money is better spent on a stronger single model + better anchors. Note temp 0 is *not* full determinism — the ED-triage work found meaningful run-to-run variability in 23% of cases ([triage reliability study](https://www.sciencedirect.com/science/article/pii/S2949882126000526)), which is an argument for code-side gates, not for voting.
4. **Don't put dollar figures, SOL date math, or posture logic in the prompt** — the compliance drafts already forbid the first two; the reliability literature independently wants all three in code.
5. **Don't trust verdict-then-evidence output** — the citation becomes decoration; enforce evidence-field-first schemas.
6. **Don't ship on QWK alone** — a scorer can hit 0.72 QWK while missing every catastrophic case; gate on high-acuity recall separately (the medical-triage lesson).
7. **Don't grow the gold few-shots past ~6–8** or reorder them casually — order is calibration state.
8. **Don't use LLM self-reported confidence as the abstention signal** — derive confidence from observability/extraction metadata in code.
