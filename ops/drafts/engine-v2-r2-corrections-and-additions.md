| `PRIOR_ATTORNEY_WALK_THRESHOLD` | **2** prior attorneys = strong negative; 1 = scrutiny/develop | credibility/effort anchor; prior-representation-count field | **Not terminal alone** — must combine with corroborating merit/liability negatives; retirement/death/fee-dispute are benign. |
| SOL gate | **2-year PI SOL** (CCP 335.1) | code Gate: `incident_date + 2yr` → urgency FLAG | FLAG only, no computed date; missing input → abstain on flag. |
| Gov-claim gate | **6-month** government-claim window (Gov. Code 911.2) + 6-month post-denial suit window | code Gate: `defendant_is_public_entity` + elapsed | FLAG only; if gov-entity AND >6mo elapsed → "likely time-barred" flag **routed to attorney**, no auto-decline. |
| Injury-severity ladder | subjective-only soft-tissue < imaging-confirmed structural < injections < arthroscopic surgery < open surgical repair; **surgical ~3-5x non-surgical**; multiplier ladder ~1.5-2x / 2-3x / 3-4x (context only) | injury-severity/objectivity anchor (ordered); drives value tier + develop-vs-sign rows | Multiplier ladder is **context, not a dollar output** — tier-only. |
| Case-selectivity band | healthy PI firms sign **~25-35%** of inquiries; **60%+ signals selection problems** | **calibration target** for the decision table's sign-rate | If engine sign-posture fires far above 25-35%, thresholds are too loose (tuning signal, not a per-case rule). |

**Pure-comparative-negligence guard (critical).** CA is **pure** comparative negligence — a plaintiff recovers even at 99% fault (**no 50% recovery bar**). Extraction field `plaintiff_comparative_fault_estimate` may **reduce** the value/develop tier but must **never trigger a decline gate**. Adjuster "you're 50% at fault" is **negotiating posture, not a legal determination** — treat as contested/unobserved and abstain from encoding it as established fault. ([Shouse](https://www.shouselaw.com/ca/personal-injury/negligence/comparative-negligence/))

**Anti-over-decline / abstention guardrail.** A documented CAALA/Plaintiff-Magazine faction **disputes the minimum-specials orthodoxy**: minimal-treatment and low-PD cases are winnable and should not be reflexively declined — the limiting factor is lawyer preparedness, not merit. Therefore **low specials + low PD + treatment gap must produce a DEVELOP / attorney-review posture, not an automatic decline** (honors no-terminal-auto-decision). Also seeds the fairness note that **absence of imaging/PD ("unobserved") is not equivalent to "no injury."** ([Plaintiff Magazine — minimal medical treatment](https://plaintiffmagazine.com/recent-issues/item/lessons-from-trials-with-minimal-medical-treatment))

### 2.2 Per-field intake OBSERVABILITY DEFAULTS + must-ask checklist floor

Partition every extraction field into three observability classes. This partition is the **core mechanism separating "normal unknowns" (benign) from "low-quality call" (re-contact)** and is what keeps the fairness rail honest.

- **`caller_stateable` (FLOOR):** legitimately expected on a first call. A missing FLOOR field down-weights **CALL-QUALITY** / triggers re-contact — it does **not** get the benign develop path.
- **`sometimes`:** caller may know it (self-report); grade on it but **cap confidence** and abstain on record-dependent severity claims.
- **`develop_only`:** essentially never from the caller; **its absence is NORMAL** → abstain-and-develop, **never a negative inference**, never a quality penalty.

| Field | Class | Notes / gate wiring |
|---|---|---|
| `incident_date` | caller_stateable | FLOOR; primary input to SOL/gov-claim FLAGS |
| `mechanism_narrative` (what happened) | caller_stateable | FLOOR |
| `location / jurisdiction` | caller_stateable | FLOOR |
| `injuries_felt` / `body_region` | caller_stateable | FLOOR |
| `saw_doctor` + `treatment_gap` | caller_stateable | FLOOR (medical existence + timing) |
| `defendant_type` (private/commercial/rideshare/**government**) | caller_stateable (coarse) | FLOOR; **primary input to gov-claim urgency FLAG** and commercial/gov routing rows — coarse observed type is enough to raise the flag |
| `already_represented` | caller_stateable | FLOOR (conflict check) |
| `prior_claims_self_report` | caller_stateable | feeds credibility/carry anchor |
| tolling triggers: `minor_plaintiff`, `latent_injury`, `defendant_out_of_state` | caller_stateable | FLOOR; feed the same urgency gate |
| `contact_info` | caller_stateable | FLOOR |
| `coverage_exists` / `defendant_carrier` | sometimes | capital gate keys off `coverage_exists` + `defendant_type` proxy; abstain when both unknown |
| `objective_findings` / `imaging` / `surgery_confirmed` | sometimes (self-report) | grade severity on self-report but **cap confidence, abstain on records-dependent claims**; **an unmentioned scan is NOT negative** |
| `defendant_impairment_observed` | sometimes | liability-booster proxy → flags DEVELOP; do **not** require a conviction |
| `commercial_indicator` (truck/company/rideshare) | caller_stateable (coarse) | raises capital/value tier via **proxy** (deeper pockets), routes to DEVELOP — never via stated dollars |
| `liability_narrative` / `defendant_scene_statements` | caller_stateable | grade liability anchor but cap confidence |
| `policy_limits` / `uim_limits` | **develop_only** | unknown = NORMAL → abstain/DEVELOP; **never a dollar in any tier**; capital/value tiers derive from **proxies** (defendant type, coverage-exists) |
| `iso_claimsearch_history` | **develop_only** | never infer "no prior claims" from silence, nor "hiding claims" |
| `dui_conviction` | **develop_only** | do **not** gate on the conviction; observed impairment is a develop signal only |
| `gvw` / `dot_fmcsa_history` / `corporate_policy_stack` | **develop_only** | missing = normal, not a quality penalty |
| `comparative_fault_apportionment` / `cost_of_proof` / `final_valuation` / `MMI` | **develop_only** | abstain; tiers via proxy only |

**Mandatory checklist FLOOR** (practitioner consensus — Talkroute/Advocate/CasePeer/Smith.ai + SOL guidance): incident date; mechanism; injuries + whether medical care was sought; **defendant status** (private/municipal/state/federal — it sets the deadline); already-represented conflict check; tolling triggers (minor/latent/out-of-state); contact info. **Two unknown-classes for the abstention logic:** (a) **FLOOR unknown → `CALL_QUALITY` flag / re-contact**, possible "insufficient-intake" decision-table row; (b) **develop-only unknown → benign abstain-and-develop, no quality penalty.**

**Lay-vocab-parity requirement.** Sources uniformly mandate lay phrasing — **"the person who hit you"** not "defendant"; **"when did this happen"** not "date of loss." Each `caller_stateable` field's extraction spec must carry **lay-synonym coverage** ("the guy who hit me" → `defendant_type`; "I hurt my neck" → `injury_region`) and abstain-and-develop unknowns **without penalizing callers who lack legal vocabulary.** ([Talkroute intake script](https://talkroute.com/law-firm-intake-call-script-what-your-front-desk-should-say/); [Advocate intake checklist](https://www.advocatemagazine.com/article/2024-october/initial-intake-a-checklist-of-factors-to-consider))

**Fault-admission guard.** Deferential/apologetic caller phrasing ("I feel terrible, maybe I could have...") must **NOT** be extracted into any fault/admission field; silence or "si/okay" to an agent question scores **UNOBSERVED, not agreement/consent.** (Honors deferential-speech != fault admission, and no-terminal-auto-decision.)

### 2.3 Spanish / bilingual fact-capture guardrails + seed lay-term lexicon

Spanish is **~89% of CA court interpretations** (562,561 events FY2021-22), so Spanish-only and code-switched intake is a **first-class pipeline**, not an edge case. Add a per-call `source_language` field (es / en / code-switched) set by language-ID **before** extraction; evaluate all anchors/gates source-language-aware. ([CA Courts Language Access](https://newsroom.courts.ca.gov/branch-facts/language-access))

**Pipeline order (config):** language-ID → speaker-role diarization → per-segment ASR + confidence + audio-quality → **source-language fact extraction** (Spanish lexicon + false-friend block-list) → **English-normalized anchor grading** → gates/decision table, with **abstention gates at any low-confidence / low-audio / code-switch / interpreter-attribution point.**

**Guardrails:**
1. **Extract from the claimant's source-language utterance, not the interpreter's English paraphrase.** Add a per-segment `speaker_role` {claimant / interpreter / agent / other} and per-segment `source_language`. A fact's citation must anchor to the **claimant's** utterance; use the interpreter turn only as translation aid. First-/third-person shifts ("he says he understands" vs "I understand") + consecutive-mode turns cause diarization to misattribute the interpreter's paraphrase — when speaker-role confidence is low, treat the fact as **unsupported → abstain/human flag** (new precondition on the citation-validity gate).
2. **ASR-disparity fairness.** Commercial ASR runs materially higher WER for AAE (~35% vs ~19%), Chicano/non-native accents, and up to ~55% higher at code-switch boundaries — silently corrupting the transcript "no citation, no claim" depends on. Attach per-token/segment ASR-confidence, propagate into citation confidence, **raise the citation-confidence threshold for low-ASR-confidence segments**, and score a missing/garbled fact from a low-confidence Spanish/accented segment as **UNOBSERVED (neutral), never negative/weak-case.** Add `code_switch_boundary` and `low_audio_quality` (telephony/SNR) per-token flags feeding the same abstention logic; prefer classical resampling over neural denoise for telephony.
3. **False-friend block-list (catastrophic mis-extraction guard).** `{intoxicado, constipado, molestia/molesto, embarazada, lastimado, disgusto}` resolved via the **Spanish sense only**. Hard rule: **`intoxicado` alone must NOT populate any intoxication/impairment or comparative-fault signal** (the Willie Ramirez case — mistranslation → missed brain bleed → quadriplegia); require an explicit alcohol/drug citation. **`molestia` must map to a real symptom slot** (do not down-grade to "no real injury"). Cognate-derived claims are "no citation, no claim" failures → abstain/human review.
4. **Culture/politeness fairness clause.** Simpatía/respeto/personalismo mean apology, agreeableness, deference, and silence are **relationship management, not fault admission or weak-case signal**. Deferential/apologetic Spanish ("perdón," "disculpe," "lo siento," "no quiero molestar," "usted sabe mejor," "lo que usted diga") must **NOT** populate a fault-admission field or lower merit grade. **Reflexive injury verbs** ("me lastimé," "me caí," "me golpeé") describe what happened **TO** the claimant → **not self-blame/comparative fault.**
5. **Somatic/folk-idiom mapping (anti-under-grading).** "nervios / ataque de nervios / susto / me quedé mal de los nervios" → possible post-traumatic/psychological sequelae + somatic cluster, **flagged for human clinician review — NOT auto-declined, NOT graded "no psych damages."** Absence of an explicit psychological label scores **UNOBSERVED (neutral)** so emotional-distress value is not silently zeroed for Spanish speakers.
6. **Per-language audit loop (required before grading feeds the decision table).** Log per language: WER proxy, citation-abstention rate, fault-admission-flag rate, average severity grade, human-override rate; **require Spanish-vs-English parity within a tolerance band.** **No terminal auto-decision on any call with elevated Spanish-path uncertainty.**

**Seed lay-term lexicon (lay es → clinical/mechanism, English-normalized).** Normalize **before** grading so severity is not under-graded by literal mapping:
